==============================
  Aeamaeth Desktop Shimeji
  Wuthering Waves Fan App
==============================

REQUIREMENTS
  Java 17 or newer
  Download free from: https://adoptium.net

HOW TO RUN
  Windows:  Double-click  Start.bat
  Mac/Linux: Run  ./start.sh  in terminal
  Any OS:   java -jar AeamaethShimeji.jar

CONTROLS
  Drag          Move her anywhere on screen
  Double-click  Cheer her up ✨
  Right-click   Options menu
  Move mouse fast  She might get startled!

BEHAVIORS
  ✦ Walks and roams along the bottom of your screen
  ✦ Climbs up walls when she hits the screen edges
  ✦ Falls with gravity when dropped mid-air
  ✦ Sits down and rests at random
  ✦ Speech bubbles with in-character dialog
  ✦ Emotion reactions: ✨ 💕 ‼ 💫
  ✦ Chases your mouse cursor occasionally
  ✦ Spawn multiple Aeamaeths via right-click menu

Fan-made. Character belongs to Kuro Games / Wuthering Waves.
