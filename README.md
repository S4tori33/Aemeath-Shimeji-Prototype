# 🌸 Aeamaeth Desktop Shimeji
### Wuthering Waves Fan App

A desktop Shimeji companion featuring Aeamaeth from Wuthering Waves!

---

## ✨ Features

- **Walks** along the bottom of your screen
- **Climbs** walls when she reaches the screen edges
- **Falls** with gravity when dragged and dropped mid-air
- **Sits** and rests randomly
- **Speech bubbles** with in-character dialog
- **Emotion reactions** (✨💕‼️💫) pop up during events
- **Startles** when you move your mouse quickly
- **Chases** your mouse cursor occasionally
- **Double-click** to make her cheer up
- **Right-click** for options menu
- **Spawn multiple** shimejis!

---

## 🚀 How to Run

### Option 1: Run from source (requires Node.js)

```bash
npm install
npm start
```

### Option 2: Use the packaged .exe (Windows)

Run `AeamaethShimeji.exe` — no installation needed!

To build the .exe yourself:
```bash
npm run pack
```

---

## 🎮 Controls

| Action | Result |
|--------|--------|
| **Drag** | Pick her up and move her anywhere |
| **Drop mid-air** | She falls with a *💫 Oof!* |
| **Double-click** | Cheers her up ✨ |
| **Right-click** | Opens options menu |
| **Move mouse fast** | Might startle her! |
